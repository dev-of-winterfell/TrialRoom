# 🛍️ Trial Room

**Define Your Look** - A personalized men's clothing platform

## 📱 About
Trial Room aggregates clothing from multiple shopping platforms and provides personalized recommendations based on body type, skin tone, and style preferences.

## ✨ Features
- 🎨 Beautiful Material Design 3 UI
- 🔄 Real-time product scraping
- 👤 Personalized recommendations
- 📊 Body type analysis
- 💾 Offline caching

## 🛠️ Tech Stack
- Kotlin
- Jetpack Compose
- Dagger Hilt
- Retrofit + OkHttp
- Room Database
- Coil
- MVVM Architecture

## 🚀 Getting Started
```bash
git clone https://github.com/dev-of-winterfell/TrialRoom.git
cd TrialRoom
# Open in Android Studio
```
